# 🍎 Fruits-360 Classifier  
### Aplikasi Klasifikasi Buah Berbasis Deep Learning (CNN)

Aplikasi Machine Learning ini dirancang untuk melakukan klasifikasi terhadap **131 jenis buah** menggunakan pendekatan **Deep Learning** berbasis **Convolutional Neural Network (CNN)**.

---

## ⚙️ Fitur Utama

- **Model CNN Klasik**  
  Arsitektur CNN dibangun dari awal menggunakan TensorFlow/Keras.

- **Antarmuka Modern**  
  Dilengkapi *web interface* interaktif berbasis Gradio yang mudah digunakan.

- **Klasifikasi Luas (131 Kategori)**  
  Dapat mengenali berbagai jenis buah, mulai dari apel hingga tomat ceri.

- **Kemudahan Penggunaan**  
  Pengguna cukup mengunggah gambar buah untuk memperoleh hasil prediksi secara instan.

- **Akurasi Tinggi**  
  Akurasi mencapai **97–99%**, berkat dataset yang bersih dan terstruktur.

---

## 🍇 Kategori Buah yang Dapat Dikenali

Model dilatih untuk mengenali 131 kategori buah berbeda, di antaranya:

- Apple (Braeburn, Golden, Granny Smith, dll.)  
- Banana  
- Orange  
- Strawberry  
- Mango  
- Pineapple  
- Grape (berbagai varian)  
- dan lebih dari 120 jenis buah lainnya.
